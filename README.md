📊 Data Analytics Project

🧩 Overview

This project demonstrates an end-to-end data analytics workflow — from raw data to business insights.
It includes data loading, cleaning, exploratory data analysis (EDA), SQL querying, dashboard visualization in Power BI, and report generation.
The goal is to uncover meaningful patterns and present key findings in an easy-to-understand visual format

🪜 Project Steps
1. Data Loading

Imported the dataset using Python (Pandas).

Checked for data types, missing values, and overall structure.

2. Exploratory Data Analysis (EDA)

Analyzed numerical and categorical features.

Generated visualizations for distributions, correlations, and outliers.

Derived initial insights and hypotheses.

3. Data Cleaning

Handled missing, duplicate, and inconsistent values.

Formatted columns (dates, text cases, numerical precision).

Created new calculated features where necessary.

4. SQL Analysis

Imported the cleaned dataset into MySQL.

Performed SQL queries for summary statistics, joins, aggregations, and filtering.

Used SQL results for validation and further analysis.

5. Dashboard Creation

Connected the processed data to Power BI.

Designed an interactive dashboard to visualize:

KPIs and metrics

Trends and comparisons

Segment and regional analysis

Ensured clarity and usability for business decision-making.

6. Reporting

Compiled the entire process and key findings into a final report.

Highlighted insights, recommendations, and data-driven conclusions.

📈 Dashboard

The Power BI dashboard includes:

Summary metrics (Total, Average, Growth %)

Filter options for region, category, or time period

Visuals: bar charts, line charts, pie charts, and KPIs

🚀 How to Run

Clone the repository:

git clone https://github.com/Nikeshyadav005/Customer_behavior_analysis.git


Install dependencies:

pip install -r requirements.txt


Open the Jupyter notebook:

jupyter notebook


Run each cell in order to reproduce results.

For SQL queries:

Load the cleaned dataset into your MySQL database.

Run provided .sql scripts.

Open the Power BI file (.pbix) to explore the dashboard.
